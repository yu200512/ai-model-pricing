视频价格估算公式：token 单价 × token 用量​
token 用量估算公式：(输入视频时长+输出视频时长) × 输出视频的宽 × 输出视频的高 × 输出视频的帧率/1024​

上述 token 用量均为估算值，准确 token 用量以调用 API 后返回的 usage. completion_tokens 字段为准。​

仅在 Session 状态为 running 时计费；处于 idle（等待用户下一条消息或工具确认）、rescheduling、terminated 状态时不计费；运行时长精确到秒，按小时出账。​
	
0.5 元/小时​


工具调用​
	
Agent 调用工具产生的费用，当前支持 web_search（实时联网搜索，返回网页标题、摘要与链接）与 web_fetch（网页内容抓取，返回正文 Markdown 或提炼文本）。​
	
按 Agent 实际调用次数计费，按小时出账。​
	
web_search：0.02 元/次​
web_fetch：限时免费​


​
计费公式：Managed Agents 费用 = 模型调用费用 + Agent 运行时费用 + 工具调用费用​
